# 肺癌患者/照护者需求与医学背景研究 v0.2

获取日期2026-10-17。阶段：桌面研究/用户需求假设；未进行本项目患者访谈、可用性测试或临床审核。来源见[SOURCES](SOURCES.md)。搜索到的医学流程帮助界定信息对象，不能直接推出患者要什么功能。

## 用户直接确认/提供

- 受众患者与照护者，DSH Desktop配套；覆盖全病程并以治疗与复诊为优先。
- 用户点明重点应有SCLC、NSCLC、确诊、穿刺、转移治疗、靶向药及指南相关内容。
- 这些产品重点由用户明确，尚未给出具体患者经历或优先次序排名。

## 患者信息差的初步归纳

| 关注点 | 常见混淆或障碍线索 | 产品机会（假设） | 证据边界 |
| --- | --- | --- | --- |
| “究竟是什么癌、分期是什么” | 影像怀疑、病理分类、分期、可切除性、治疗目标容易被当成同一答案 | 并列原文、来源、时间、未知及需解释项；不自动下结论 | NCI/ACS为患者教育，需中国患者走查 |
| 穿刺/取材为何做、材料够不够 | 不同取材路径、标本/病理/分子检测时间线分散；担心再次穿刺 | 取材—标本—检测—报告关联，记录送检/不足/补充及问题 | IASLC专业图谱说明样本前分析复杂；不表示患者最在意排序 |
| “基因检测是不是阴性/没做” | 组织、血浆、检测覆盖范围与结果状态有差异；未检出不必然等同不存在 | 保留样本/方法/覆盖范围/变异原文，分开待出/未检出/未测/不足/VUS | IASLC及检测说明；具体临床解释须核指南与专业审核 |
| 靶向药是否适合我、国内能否用 | 基因名不足以判定药物；变异、阶段、线次、标签地区、支付/院内可及不同 | 变异级药卡和个人医嘱记录，解释已知/未知与可问的问题 | LUNGevity讨论工具说明患者需能问检测与治疗；美国监管资料不能推断中国可及 |
| SCLC是不是“没靶向、只有化疗” | 临床知识持续更新，放疗/免疫/后线药物不同于NSCLC驱动基因药 | 独立SCLC路径内容包与版本，不复制NSCLC基因导航 | NCI/FDA可见部分更新；本轮CSCO全文未获取 |
| 转移是不是只看一个数值/一张片 | 部位、比较对象、治疗时间与症状常跨多份材料 | 一图秀按部位/实际疗程/影像时间并列，保留缺项 | NCI/ACS专业背景，需患者走查验证有效性 |
| 进展后为什么又做活检/有没有其他治疗 | 新检测、耐药、组织学变化与局部/全身治疗选择需专业沟通 | 保存团队提出的再评估理由和既往/当前证据，生成问题单 | 现阶段以专业来源解释任务结构，不提供推荐路径 |
| 日常症状、吃饭和心理压力 | 体力、气促/治疗副作用、等待结果、污名与家庭分工可增加记录负担 | 可只记一项；给来源支持、实际联系/团队回复入口；隐私可选 | 中国肺癌专门直接研究仍需扩展，本轮患者证据不足 |
| 家属代办与信息分享 | 患者与家属可能对知道/分享哪些信息有不同愿望 | 记录主体/代录者，分享摘要预览，私密信息独立 | 中国晚期癌症定性研究提示偏好并非完全一致；不推及所有家庭 |

这些归纳用于安排研究及原型，不声称普遍患病人群比例或已经验证。

## 直接研究与患者工具

1. [中国肺癌患者/照护者化疗期间互惠体验](https://pubmed.ncbi.nlm.nih.gov/39636433/)：2024定性研究摘要，15对患者与照护者，报告沟通、角色变化、适应和照护挑战；目前仅核对摘要，单中心/小样本且阶段特定。
2. [中国晚期癌症患者与照护者信息需要](https://pmc.ncbi.nlm.nih.gov/articles/PMC8186148/)：2021定性研究，17名患者、15名照护者；关注信息内容、未满足原因、偏好与信息角色；非肺癌单病种，参与者已报告信息需要。
3. [LUNGevity Biomarker Discussion Guide](https://www.lungevity.org/biomarkerdiscussionguide)：患者与专业人员共创工具，支持理解检测如何关联治疗/试验及提问；美国患者支持资源，产品流程可参考，不能当中国患者验证。
4. [LUNGevity分子检测障碍项目](https://www.lungevity.org/about-lungevity/patient-focused-research-center/barriers-to-optimal-care/barriers-to-biomarker)：明确患者端教育需与医疗人员侧改进配合；工作台可缓解部分信息/准备问题，不能暗示替代医疗系统解决检测可及性。
5. [ACS肺癌就诊问题](https://www.cancer.org/cancer/types/lung-cancer/detection-diagnosis-staging/talking-with-doctor.html)：确诊、治疗决定、治疗中、随访问题目录；患者教育，不等同访谈。

## 用户任务而非指南流程

将“疾病流程”转译为自愿任务：有一份材料想看懂；被告知需要穿刺，想知道应询问什么；多报告混在一起，希望整理；开始药物后想知道怎样按医嘱留记录/说明困扰；身体某处变化后要准备向谁询问；复诊时快速带上摘要；累了只记录最要紧的一件事。具体入口顺序和收益待原型及患者验证。

## 后续低负担研究计划

招募不同诊断阶段、NSCLC/SCLC、靶向药使用者/照护者及不同数字能力的参与者；分别问“最近一次收到病理/分子报告、穿刺或治疗变化时，实际做了什么”“最费力的是哪一步”“家属何时帮忙、何时不希望代答”“愿意额外记录多少”。不要在访谈中假设参与者是EGFR阳性、吸烟或晚期。

先做任务走查，不问抽象“喜欢什么功能”：无资料刚确诊、只有一份模糊报告、多报告且精力不足、正在记录口服靶向药、SCLC放化疗复诊、报告提出脑/骨变化。观察理解、负担、错误传播、能否停止/恢复。真实用户研究仍待开展。
