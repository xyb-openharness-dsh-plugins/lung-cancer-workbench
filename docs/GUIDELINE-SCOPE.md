# 肺癌知识范围、指南与时效合同 v0.2

核对日2026-10-17。来源清单见SOURCES；本文件定义产品内容管理，非个体治疗路径。

## 当前取得什么

- NCI NSCLC/SCLC PDQ患者版及专业版可访问，属于美国持续维护的循证摘要，不冒称中国指南；本轮浏览相关诊断/分期/治疗段落，未对每个方案逐条专业审定。
- IASLC 2023分子检测图谱入口与目录可读，涉及取材/检测/解释；图谱全文未逐章审查。IASLC分期项目明确第9版的更新背景，故模型必须保留分期版本而不硬编码第8版。
- 卫健委《原发性肺癌诊疗指南（2022年版）》找到官方发布检索索引，但通知/PDF本轮直取失败，**未完成完整原文审查**。2024《肺癌筛查与早诊早治方案》属于筛查/早诊文件，不能代替全治疗指南。
- CSCO官方2026 SCLC指南活动/发布资料可访问，证明该年度资料存在；不等于已取得完整条目。2026 NSCLC完整原文和当前完整NCCN均未取得核对。不能写“已按照2026全部最新指南推荐”。
- FDA具体药品批准通知可核对部分靶点/阶段/既往治疗条件；它证明该次美国批准事件，不等于当前中国说明书，也不独立证明截至今天标签没有后续变化。
- NMPA/CDE当前逐药标签、撤回/变更及医保/医院可及性未完成系统核查。知识库发布前必须补齐中国条目；不能以搜索结果缺失推断未获批。

## 内容路由

1. 原发来源：肺原发/其他癌肺转移/未知分开。
2. 组织学：NSCLC（细分组织学）、SCLC（含复合）、转化事件、其他/未知；病理转化是时间事件，不改写历史。
3. 分期：体系/版本/日期/TNM前缀/原文；SCLC的局限/广泛期作为另一维度。分期不能替代可切除、手术耐受、治疗目的或患者意愿。
4. 检测：样本/时间/方法/覆盖范围/特定变异/结果类型。检测未完成时不匹配个人治疗选项，但可提供术语/检查目的与沟通问题。
5. 治疗背景：围手术期、局部晚期、转移/复发、既往药物、放疗、进展描述、合并情况与医生意见。不得只凭基因命中一张药卡。
6. 来源地区：中国/美国/国际分别标记；“有国外证据”“中国已批准”“中国医保可支付”“某医院有药”四项独立，未知保持未知。

## 知识条目最小合同

`resource_id/version/type`（指南/说明书/患者教育/原始研究/试验/费用/服务）；标题/机构/URL/章节或页码；发布日期、更新日（未知可空）、获取日/内容hash；地区、病理/阶段/变异/前治条件；简短可读解释；支持的具体说法；许可/摘录边界；获取状态、专业审核人/时间、有效期/复核日、替代版本和撤回状态。

药品批准另有`indication_id`，保存药物/组合、监管机构、批准事件日、条件/批准性质原文、标签版本与后续核验状态；新闻/研究/标签互相链接但不合并。

## 更新与失败

发布前逐条审核实际展示的临床解释/药物条件。运行时显示最近核验日，药品/招募/费用这些易变内容默认按30日复核窗口作为工程提案；窗口不是医学有效期，监管撤回/安全变更可立即失效。稳定术语解释建议半年复核，仍需责任人确认。

有新版本时保留旧内容及历史输出来源；标注引用该版的解释/摘要需重看。不在患者库更新时悄悄改旧导出。来源不可用保留最后快照并标时点，只做材料整理/问题准备；不能把过期知识转换成当前个体选项。

条目未完成本地标签核验时，可在带地区/状态的通用知识视图展示经审读信息，不进入“与你有关的已核验用药条件”。无专业审核的条目只用于开发规格/研究草案，不宣传为可上线医学内容。
