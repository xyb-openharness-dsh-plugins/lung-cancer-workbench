# v4.2.6 Demo 审核

日期：2026-10-20。对象：开发者指定的本机静态服务 v4.2.6 与对应项目文件。此轮只审核，不修改原型或应用代码，不等同于Desktop发布验收。

## 发现

1. **P1：窄屏抽屉的键盘焦点可进入遮罩后的业务区。** 800px窗口展开AI抽屉后，从“加宽”按钮连续4次Shift+Tab，焦点落到背景“去档案管理查看原件”。`.workspace.inert=false`，面板缺少模态语义及焦点约束。鼠标遮罩不能阻止键盘误操作。建议仅抽屉模式启用模态对话语义，打开时移入焦点、限制Tab循环、背景inert，关闭后恢复到实际触发入口；桌面分栏保持非模态。定位：`docs/prototype/agent-pane-v42.js:21`、`docs/prototype/agent-pane-v42.fragment.html`。

2. **P2：窄屏调宽显示与实际尺寸不一致。** 800px窗口中面板实际固定420px，点击“加宽”使显示35%→37%，面板仍420px。因为窄屏CSS采用固定宽度，而宽度动作只更新flex-basis。建议抽屉隐藏/禁用百分比调宽，明确固定抽屉宽度；或让控件实际调整抽屉尺寸，避免数字变化但界面不动。定位：`docs/prototype/agent-pane-v42.css:28`、`docs/prototype/agent-pane-v42.js:7`。

## 本轮已实测通过

- 顶栏按钮打开/隐藏，右缘入口可打开。
- 默认35%，加宽控件及双击分界线恢复35%。
- 小于900px进入带遮罩的抽屉，隐藏拖动分界线；Escape能关闭。
- 系统深色模式下根背景仍为rgb(243,249,252)。
- 一图秀外边距16px、正文14px、卡片内无操作按钮。
- 指标卡点击显示折线图，再次点击卡片返回数字。
- 检查过程未见页面脚本错误。

未覆盖完整上传解析、临床试验搜索与全部业务页，不给出全产品一致性百分比。原生conversation在Demo中仍为明确标记的宿主插槽，真实消息、会话复用与附件需要DSH Desktop RC实机验收。

## 结论

v4.2.6保留此前一图秀确认项，AI入口和宽度操作更清楚。可作为下一轮实现参考，建议先修复上述两项再锁定。窄屏抽屉是新增布局分支，采纳后同步SPEC、面板设计与应用实现，不能仅停留在HTML。
