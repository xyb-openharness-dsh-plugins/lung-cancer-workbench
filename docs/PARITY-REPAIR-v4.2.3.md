# 原型一致性修复清单（基线 v4.2.3 / 候选 0.1.2-rc.9）

日期：2026-10-20。基线原型：`docs/prototype/lung-workbench-v4.2.3.html`（= v4.2~v4.2.5 同一份产物）。
对照对象：`lib/client.js`（DSH Desktop 工作台客户端）+ `lib/demo-cases.json`。

结论：**当前实现与原型的一致性约为 55–60%**。缺口集中在「三个一级模块整体缺失」与「其余页面的子页结构被简化为记录列表」。
本文先列出可核对的修复点，再逐项落地。视觉一致性必须在 DSH Desktop 实机逐页核对后才能声称 ≥98%；本文不代替实机验收。

## 对齐口径

原型 v4.2.3 由 `scripts/build-prototype-v42.py` 从冻结的 v4.1 页面脚本 + 应用 CSS/图表/档案流/AI 面板拼装。
因此「原型」= v4.1 的信息架构与文案（`.card / .grid.g2 / .list-row / .priority / .stat / .tag / .info-box / .subnav`），
「应用」= `.wb-card / .wb-grid / .wb-item / .wb-priority / .wb-dashboard-stat / .wb-tag / .wb-info-box / .wb-subnav`。
两者色彩令牌已基本一致（paper `#f4f9fb`/`#f3f9fc`、blue `#267ba5`/`#17638c`、orange `#df7930`/`#e8873d`、green `#377963`/`#277b62`），
**本轮不重写视觉令牌，只补齐结构、文案与缺失模块**。
