# 四核心模块与综合照护子规格 v0.2

从属于SPEC v0.2。以下为待实现合同，功能ID见FEATURE-INVENTORY。

## R 病情整理

**R01资料库**：批量文件选择、类型/日期/来源筛选；保存原件hash和版本，显示导入/排队/解析/部分成功/失败/取消。重复提示，不静默覆盖；加密/坏文件保留原件并给替代输入。TXT/MD等本地路径与云解析分清，云服务发送范围可预览。

**R02整理草稿/核对**：先短摘要，分句可展开出处和状态；疑点按当前任务依赖排列，建议每轮最多三项、可全部稍后。原文与候选并列，单位/日期/样本/变异高亮；接受/改正/拒绝/暂跳过均有结果。按明确字段组接受，不能“关闭弹窗=全部确认”。重解析生成diff，保留已接受旧版。

**R03诊断与分期**：NSCLC/SCLC/混合/不明分别显示原文与时间；同一患者多个病理断言可并存。TNM及版本、c/p/yp原文、总分期、局限/广泛期、可切除/手术耐受、团队目标各自来源。多灶不等于自动多原发，也不自动认转移；冲突列待核实。

**R04取材与检测**：以“这次取材→哪些标本→病理/分子/PD-L1各自状态”显示。支持穿刺、EBUS/支气管镜、手术、胸水细胞学原文；血浆是独立样本。行政借片/寄送、样本不足/失败、补送/重复检测形成可回顾任务。用户可记下院方准备须知，产品不代开检查/停药安排。

**R05复诊汇总**：选择日期范围/材料/重点问题→显示缺项和冲突→摘要/一图秀/问题预览→选择Agent/导出→收藏回顾。无需从头填病史。病理未定、缺治疗时间、全批未核对仍可生成明确标记的草稿，不强行补诊断。

## M 指标检测

**M01结果列表**：按已存在指标展示，不铺空白检查墙。通用血常规、肝肾、电解质和营养相关结果；CEA、CYFRA21-1、NSE、ProGRP等按个人实际资料启用，字典项不是推荐检测清单，不用指标名诊断病理。定性、比较符、检测限、单位、参考区间、方法、采样/报告日期精度均保留。

**M02趋势**：真实纵轴、点/表、日期范围、可见分组依据、参考带来源。日期不明留列表，报告日代采样日须标注；方法或单位不明不混线。单条只画点，缺值不作0，`<5`不作精确5。PD-L1、基因和IHC在检测事件中展示，不作为普通连续曲线。

**M03质量处理**：同日冲突、不同样本/方法、单位缺失、原件失效可纠正，保留历史。趋势不推断疗效/复发/转移；已报告异常与系统比较符号分开。

## O 独立病情一图秀

**O01一图秀页面/共同时间窗**：作为独立一级Tab，从看板和复诊准备可进入。主画面为可读时间图，控制区含日期范围（3/6/12月、全部及可扩展自定义）、指标多选清单、事件轨道开关。取材/病理/分子检测、手术、系统治疗、放疗、影像及部位、可选症状/营养使用共同日期窗口；计划/待定/实际以文字和形状区分，不能只靠颜色。密集同日事项可聚合，展开保留每项来源。空数据仍可解释如何开始；无指标时事件轨道仍可用。

**O02多指标图与动态**：指标清单显示名称、单位和是否有可画记录；支持同时勾选多项、清除/全选、日期范围联动。异单位或不同检验方法默认用独立纵轴小图（small multiples），共用时间轴但不共用数值刻度；只有单位/方法/参考范围可比且用户明确选择时才可同图叠加，并始终标轴。缺值不连成零，单个值画点而非趋势线，日期精度不足的记录进入列表。点击数据点显示采样/报告日期、原始数值、单位、参考范围、样本/方法、核对状态和来源入口。窗口/勾选变化后清除失效点选详情；返回详情后保留筛选和滚动位置。图形需有等价列表/键盘可达内容，并支持减少动效。

**O03指标卡水平翻面**：每张卡独立控制左右翻面，动画轴固定为Y轴 `rotateY(180deg)`；不改成上下堆叠/纵向折叠。正面为指标名、最近已确认值/单位/日期、来源/状态；背面为最近最多5次记录的迷你趋势、清晰刻度/日期及返回提示。翻面按钮有可读名称、`aria-pressed`状态和键盘操作；动画减少设置下即时切换。窄屏改为单列但仍保留正反面语义；不得因卡片无记录而显示正常或空值为零。

**O04肺癌事件/快照**：至少支持穿刺取材、样本送检/不足、病理与分子结果待出、手术及术后病理、靶向/化疗/免疫实际治疗、放疗计划和已完成分次、影像与脑/骨/胸膜等部位事件。治疗事件显示计划/实际/暂停等原文状态，点开回到源记录；事件并列不暗示因果或疗效。记录轨道、筛选日期、病例版本和备注生成快照；源更正后旧快照标旧版、不静默改写。心理私密默认隐藏。原型合同见 [GAP-ANALYSIS](GAP-ANALYSIS.md) 与 [肺癌桌面原型](prototype/lung-workbench-v1.html)。

## C 临床与用药

**C01治疗历程**：方案、阶段/目的/线次（可未知）、既往治疗背景，手术/系统用药/放疗可并行。计划、实际、延期、暂停、结束及更改理由原文分开；放疗保存部位、技术、计划/已完成分次及剂量原文，不能由出勤自动认定给足剂量。

**C02分子/PD-L1档案**：按检测批次、样本和报告版本呈现结果；变异类别、外显子/HGVS/融合伙伴/丰度/覆盖范围原文、PD-L1克隆及评分方法可展开。不确定/待出/失败不是阴性；组织与血浆不一致保留并列。

**C03靶向药与治疗知识**：查靶点、具体改变、药品或医生方案；药物卡包含机制、研究/批准地区、阶段/既往治疗条件、证据日期、来源及未核实项。区分“我的医嘱”“知识介绍”“我想问的问题”。支持相关性解释和条件对照，不自动设定下一线。记录个人用药、复查医嘱、合并用药、服用自述，问题可一键带来源留存。

**C04转移与再评估**：部位/时间/证据→实际局部/全身治疗→症状/功能变化→团队评估→待问/再取材。进展/耐药/转化保留谁在何时依据何材料提出。PCI与已存在脑转移的治疗不同标识，骨转移与原发骨癌不同内容路由。

**C05试验检索**：原发癌种/病理、登记分期、分子条件、地区/中心/招募筛选→列表→原登记详情→收藏/对照/Agent。公开条目不可混入患者事实库；本地快照标采集日期及源更新时间，联系前复核中心。

**C06对照/关注**：条款原文与所选患者记录版本并列，显示找到资料/缺项/需中心解释；不自动输出入组符合或概率。收藏保留登记ID和当时版本，结束条目不消失。

**C07来源与指南**：疾病/地区/版本/章节、摘要许可、获取/核验、临床审核状态、替换与过期。能查“为什么这里这样解释、还缺哪条依据”；不把新闻稿变说明书。

## N/P/A/V 综合照护与回顾

**N01/N02**：任选体重/进食变化/困难即可保存；可关联食管放疗、恶心/腹泻或水肿自述但不自动因果。查看通用支持和整理营养师问题，记录专业建议；不预设能量/蛋白/限水目标。

**P01/P02**：主观感受、睡眠、担忧及想要帮助，可跳过且可仅阅读。等待检测/复查、刚确诊、耐药与污名各有候选支持入口；照护者自己记录属于照护者。共享与私密分开，派生结果继承限制。

**A01/A02/A03**：既有预约/检查/处方随访、行政标本事务、症状与实际联系记录。紧急帮助卡不依赖AI问答；联系方式缺失有替代说明。本机待办不等于后台通知，AI选项不自动排成治疗医嘱。

**V01/V02/G01**：收藏来源/问题/任务/真实导出，重新打开保留版本；PDF/JPEG/HTML/Markdown/DOCX各验真。原生Agent跨模块统一快照/引用/隐私/失效规则，详见AI-ASSISTANCE。


**C08术后活动/肺功能自述**：手术回顾下可选记录术前活动基线（如能否连续走/爬楼、需否停下休息；术后回忆需标“回忆自述”），之后用相同问题记录当前情况。可只填一项；呈现为患者自述，不换算肺功能、不生成恢复等级。静息/平卧气促及明显变化的帮助文案由临床审核，不由模型分诊。

**C09胸腔操作记录**：在胸水/胸膜部位时间线下逐次记录诊断性穿刺、置管/引流等操作；可填写日期精度、左右侧/部位原文、目的、引流量与单位、性状原文、机构、细胞学/病理来源、操作前后气促自述。多次操作独立保存；缺性状/量不阻塞保存，不推断复发、疗效、引流时机或管路护理方法。

**C10免疫治疗中的症状回顾**：从本人实际免疫治疗事件进入，症状项可选、多次记录，至少能记其他自由文本；症状发生日期与治疗事件可在一图秀并列。提示跟随患者本人团队提供的联系方式，不诊断irAE、不建议停药；症状清单和紧急措辞临床审核前不进入面向患者的正式知识内容。

**C11咯血联系入口**：症状表单允许记录血性痰/咯血及伴随表现；常显联系动作，不要求先填档案、问AI或做严重度自评。不得把少量血丝指导为“等下次复诊”；严重/持续出血或伴呼吸困难、胸痛、头晕/晕厥须直达当地急救入口。精确分级/时限文案和中国本地联系方式未经临床审核不得上线，离线仍可打开已审核联系卡。

## 贯通验收

穿刺标本→病理→同批分子检测→个人医嘱→实际用药→复查影像/化验→同时间窗一图秀→复诊问题与导出，全程复用ID。任一源更正能找到受影响的草稿/解释/快照；没接受的候选和私密记录不能静默进入正式曲线/分享。
