# v0.4 合并修复设计与执行合同

2026-10-18 用户确认：以肺癌原型 v4.1 为视觉和交互基线；曲线轻度平滑、不过冲；改善记录窗口上传；支持主流文档/图片及 HEIC；导入病历→解析→人工确认→SQLite；新增档案管理 Tab 管理输入与输出文件。合并此前一图秀一致性审计，不再使用不存在的 v5 作为基线。

## 一图秀

恢复 v4.1 的主区多指标同窗回顾、3/6/12个月及全部时间窗、事件分类筛选、治疗时间轨、独立翻面卡；右侧保留读图提示、肺癌治疗事件类型和病例概况。新增结果、切换指标、数据点来源详情均形成闭环。

曲线用保形三次插值，控制点保持在相邻真实点值域内，不制造峰谷；真实数据点始终可见。不同名称/单位/方法严格分组，空值/无有效日期不绘制为零。先按日期排序再取窗口；最新值以报告日期为准。同日不同记录不合并为平均值。单点不连线，减少动效偏好可关闭翻面动画。

## 上传与档案管理

“记录一件事”和病情整理/档案管理均有具名文件选择与拖放区，显示格式、20MB/文件限制、逐文件进度和成功/失败结果。原件先以不可覆盖文件保存到当前真实病例的本机目录，SQLite 保存索引/hash/状态；相同病例重复内容复用已存在原件。演示病例保持只读。

接受 PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、RTF、TXT/MD/CSV/JSON/HTML，以及 PNG/JPEG/WEBP/GIF/BMP/TIFF/HEIC/HEIF。文件类型须与文件头匹配；HTML 原件只下载、不以可执行页面内嵌。HEIC/HEIF/TIFF/BMP 在 macOS 使用系统 sips 转 PNG 预览副本；保留原件。转换不可用或失败时保留原件并显示失败，不能宣称解析成功。

档案管理有“导入原件”和“导出文件”二级列表。原件可预览/下载、查看解析状态、解析、查看候选；输出可重新下载，显示文件名、格式、创建时间和大小。文件操作严格按当前病例隔离。首次无档案时提供创建/切换入口。

## 解析与确认

TXT/MD/CSV/JSON/HTML 进行本机文本提取。PDF、Office 和图片走 MinerU；每次云端解析前要求显式同意发送当前文件至 MinerU，失败保留原件，可重试。安装/服务不可用如实说明。不把系统文本或模型生成内容执行为代码。

解析文本、引擎、时间、版本及同意时间持久化。按原文生成保守候选，保留来源摘录，不自动生成诊断、疗效、分期或治疗建议。病理/分型、分子原文、分期原文与明确带单位的指标可分别成为候选；未知日期保持未知。用户勾选、修改日期/内容/单位并核对原件，确认后在一个 SQLite 事务内写入 accepted 记录、审核决策及候选关联。重复确认和过期解析版本/病例修订拒绝写入；候选保持可见供继续处理。

## SQLite 增量迁移

在既有病例/记录/决策表基础增加 documents、document_candidates、export_artifacts。建立病例/原件外键、内容去重、状态 CHECK、JSON 有效性 CHECK、解析版本及查询索引；旧病例及原件不覆盖。原件和解析文本先持久化再产生候选，候选确认后才进入病例事实。一图秀来源详情可转到关联原件。

## 验收

覆盖：旧库升级、批次部分失败、重复导入、跨病例访问拒绝、HEIC转换与失败、本机文本解析、云端未同意拒绝/超时、候选编辑确认/重复确认/并发修订拒绝、导出文件重新下载、平滑曲线无过冲、单位方法隔离、翻面返回、数据点键盘、零/单/多点与私密记录排除。发布目标仍为 DSH Desktop app 内部 Harness RC；实包安装后由用户手工重启。

## 2026-10-19 上传入口的明确位置与流程

记录弹窗正文输入框下方常显“＋ 上传文件”，不得仅提供档案列表入口。选择文件后在同一弹窗继续四步进度“上传文件→解析→核对→保存”；保留原手填草稿，允许返回，保存前必须展示可编辑候选并显式核对，保存后可回查原件与输出。多文件分别处理，未知日期不伪造为今天。关闭或返回不能隐式确认候选。HTML中区分真实本机文本读取与未实际解析的演示候选；产品接通与SQLite入库另行验收。


## 2026-10-19 一图秀浅色与指标卡背面折线图

按开发者最新截图意见，一图秀主内容背景固定为标准浅蓝 `#f3f9fc`，卡片/图表为白色 `#fff`。即使外层选择深色模式，也不将一图秀内容转成深色；其他页面的主题开关保留。HTML与应用共享同一图表渲染文件和样式。

指标卡正面整面为可键盘操作的按钮，展示最新值、单位与报告日期；点击后沿Y轴横向翻转，背面展示对应名称/单位/方法/实验室的真实指标折线图。背面采用当前时间窗口和同一日期映射、全期稳定纵轴范围、原始数值刻度和保形轻度平滑；缺失不补0，单点不连线，不可比方法仅显示点。点选测量点查看对应来源，也保留“查看来源”和“返回正面”。各卡独立，重播主图不重置翻面。隐藏一面使用aria-hidden/inert阻止误操作，减少动画偏好直接显示终态。

浏览器实测：CEA背面显示4个真实模拟测量点与对应折线，只有1张翻面，其余卡保持正面；外层深色时一图秀背景rgb(243,249,252)、背面白色。构建及45项测试通过，包括卡片背面确实存在指标SVG、返回、重播保留状态及键盘来源详情。[最终截图](reviews/prototype-v4.2-metric-flip-trend-light.png)。源码与HTML已更新，尚未更新Desktop安装包。
