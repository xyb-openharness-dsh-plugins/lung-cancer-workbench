# 小肺宝 DSH 原生 AI-IDE 面板设计与验收

状态：用户已确认右侧原生 Agent 布局。实现目标为 DSH Desktop app 的 `customFrame` 工作台；不适用于 DSH Web 或官方发行版。

## 已确认的布局合同

- 小肺宝工作台留在主区域；DSH Desktop 原生 conversation 节点位于最右侧，不自制聊天 UI。
- 首屏不自动创建会话。用户点击顶栏“打开 AI 对话”后，才核验工作台 owner 并复用绑定会话，或通过目标 RC 的目录选择器与 `ensureSession` 建立一个会话。
- 右栏默认宽度 35%，允许 25%–45%；用户宽度偏好本机保存。隐藏只收起面板，不结束会话；重开时重新核验 owner。
- 中间 splitter 支持指针/触控拖动、方向键、Home/End，并暴露 vertical separator ARIA 值。右侧顺序和拖动比例均相对于工作台容器，而非整窗。
- 工作区宽 620–760px 时顶栏换行，主导航仍显示图标和文字；窄于 620px 后才折叠导航文字。临界条件用 CSS 容器宽度计算。
- AI-IDE 一键带入使用独立的选择/预览/同意步骤。仅列已确认、由用户逐项勾选的诊断、检查、治疗和指标记录；症状、照护、心理、候选和未选择内容默认排除。不保存整份草稿到病历。
- 调用原生输入框前读取其状态。存在现有草稿、附件/图片引用或发送过程时拒绝写入，保留原内容并提供复制路径。回复由 DSH 原生界面展示，不能自动写入病历或转为治疗建议。
- 会话归属异常视为不可验证，不当成“不归属”后反复创建。并发打开/发送共用一个创建 Promise；用户取消目录选择时不留工作台资料副作用。

## 病例上下文与文件附件

“选择资料并预览”仅用于从当前真实病例档案挑选已确认的可分享记录；未选档案、只读演示档案、无已确认记录分别提供明确提示和下一步入口。这个弹窗不上传或解析文件。文件/图片附件走 DSH Desktop 原生对话区的附件控件（受 Desktop、模型和附件服务能力限制），肺癌工作台自身的病历导入与解析核对另由档案管理提供（源码待发布验收）；不得显示虚构的本地文件上传成功状态。


## 2026-10-19 主原型与浅色正文修订

主HTML已将右栏整合进 [v4.2](prototype/lung-workbench-v4.2.html)，不再只在独立状态稿里展示。首页与顶栏提供“打开 AI 助手”，顶栏独立隐藏按钮、面板内隐藏按钮均可收起；默认关闭，展开35%，拖动/触控/键盘/滑块调整25%–45%，仅宽度偏好写入本机localStorage。业务页状态和文件草稿不随收起/调宽重建。正文沿用页面浅色/白色表面，不额外引入深色聊天背景；真实消息UI及其主题由DSH原生组件负责，不注入或仿制聊天。

采用脚手架实际模板：[主合同](../../xyb-workbench-starter/prompts/DSH-AGENT-PANE-INTEGRATION.md)、[落地模板](../../xyb-workbench-starter/docs/20-AGENT-PANE-DESIGN.md)。独立HTML显示“宿主模拟 / 非真实DSH会话”，并可预览加载、失败、已有草稿冲突；不伪称已绑定、已发送或已收到回复。

应用源码继续渲染宿主传入的 `conversation`，本轮补齐首页入口与顶栏独立隐藏，首次点击仍走owner核验、会话复用/创建与防重，不在加载时创建会话。工作台壳成为响应式容器，620–760px顶栏换行保留导航文字，<620px折叠文字。失去pointer capture后停止调宽。

实测：35%拖到约30%；键盘End到45%；隐藏重开保留宽度；704px工作区导航文字可见，495px工作区折叠至62px图标栏，两者无页面横向溢出。AI正文背景rgb(255,255,255)。构建与45项测试通过，测试包含原生节点位置、键盘调宽、顶栏隐藏及延迟创建防重。[审核截图](reviews/prototype-v4.2-ai-pane-light.png)。尚未更新安装包，真实Desktop RC会话渲染/消息收发/拖动需实机验收。

## 2026-10-20 v4.2.6：调起、开关与调宽的交互口径

原型产物 `prototype/lung-workbench-v4.2.6.html`（同一构建脚本生成）。以下为**已实现的交互合同**，用于后续把同样的行为搬进应用源码。

| 操作 | 行为 | 约束 |
| --- | --- | --- |
| 调起 | 顶栏「AI 对话」、首页「打开 AI 对话」、右缘竖排把手「AI 助手」 | 三个入口都只是打开；顶栏那个兼作开关 |
| 收起 | 顶栏变「隐藏 AI 对话 ×」、面板内「隐藏 ×」、抽屉遮罩、Esc | 收起不结束会话，宽度保留 |
| 调宽 | 左缘 16px 拖动、`− 缩窄 / ＋ 加宽`（每次 2%）、滑杆、方向键 ±2（Shift ±6）、Home/End | 25%–45%，默认 35%，写 `localStorage` |
| 复位 | 左缘连按两次 = 35% | 与 `End`/`Home` 不冲突 |
| 窄窗 | 容器 < 900px 自动改右侧抽屉 `min(420px,92%)` | 抽屉态不提供拖动，避免压没业务区 |

面板正文必须保留三条否定式说明：不新建/不接管会话（归属由 Desktop 判断）、不自动发送也不覆盖原生草稿、不把回复写进病历或当治疗建议。原型插槽明确标注「宿主插槽 · 非真实会话」，不伪造消息、模型选择或发送成功。

**未完成（不得当作已验收）**：应用源码 `lib/client.js` 尚未加入右缘把手与 ±2% 按钮，也没有连按两次复位；安装包未重打，本机 Desktop 的 0.1.2-rc.2 早于面板实现。`customFrame` 下的会话创建、owner 复用、草稿冲突与消息投递仍待实机验证。

## 2026-10-20 rc.9：首轮开发完成并装机

应用源码 `lib/client.js` 与原型 v4.2.6 对齐后落地：

- 收起态右缘新增竖排把手 `.wb-ai-edge`（`aria-label="打开 AI 对话栏"`），不占业务宽度，任何页面可调起；打开后立即移除，避免与顶栏开关重复。
- 工具栏改为 `.wb-ai-stepper`：`− 缩窄` / 滑杆 / 百分比 / `＋ 加宽`，到达 25% 或 45% 时对应按钮 `disabled`。
- 左缘 `onPointerDown` 增加 340ms 内二次按下的复位（`nativePaneResetRef`）；方向键步长 2%，`Shift` 6%。
- `splitter` 与 `#wb-ai-pane` 改为**始终渲染**，用 `display` 与 `aria-hidden` 控制可见性——宿主传入的 `conversation` 不再因收起被卸载。

验证边界：本地 UI 验收环境用存根宿主（`isActive/ownsSession/currentSession/ensureSession/pickDirectory/sessions.scope`）跑通，**不等于**真实 Desktop 的会话创建、归属复用、草稿冲突与消息投递；这些仍需重启 Desktop 后实机验收。`node --test` 8 项 client-render 失败为陈旧 hook 下标测试，待重写 harness。
