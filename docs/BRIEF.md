# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：肺癌患者及照护者；用户已确认全病程覆盖，治疗与复诊为优先主线

场景：设计假设：围绕就诊与日常照护，减少资料分散、信息难懂和沟通遗漏；主线为全病程内的治疗与复诊准备，肺癌专属支持待SPEC细化

核心流程：
1. 设计假设：选择本机资料目录并导入报告
2. 设计假设：核对候选信息，整理关心的问题和照护困难
3. 设计假设：借助原生Agent理解资料并准备就诊沟通内容
4. 设计假设：保存可回顾的资料与沟通结果

完成结果：设计假设：得到来源可追溯、可核对、可回顾的就诊准备材料；具体可观察成功标准待患者/用户走查确认

初始布局选择：business-first
