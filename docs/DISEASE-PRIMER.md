## 1 定义（`definition`）

肺癌是起源于支气管黏膜或腺体上皮的恶性肿瘤。按病理与治疗路径分成两大类，**这两类不能合并叙述**：

- **非小细胞肺癌（NSCLC）**：腺癌、鳞状细胞癌、大细胞癌等亚型。治疗分层看三件事——分期、驱动基因检测结果、PD-L1 表达状态。
- **小细胞肺癌（SCLC）**：病理与治疗路径都与 NSCLC 不同；另用「局限期 / 广泛期」二分法描述范围。

- **分期体系**：TNM，由 AJCC / IASLC 维护。`docs/SOURCES.md` 记录卫健委 2024 年筛查与早诊方案引用 TNM 第 8 版；`docs/GUIDELINE-SCOPE.md` 记录 IASLC 分期项目页已说明第 9 版的更新背景。因此本台把「分期版本」当必填字段，**不硬编码第 8 版**。
- **两套体系不互推**：TNM 和 SCLC 的局限 / 广泛期是两套描述；TNM 也不能替代可切除性、手术耐受、治疗目的或患者意愿。
- 不写「早期 / 晚期就该怎么办」这类判断：分期原文照医生写，本台不改写、不换算。

## 3 目前治疗全景概要（`landscape`）

按病理类型与病期分组，只列**手段类别**，不含剂量、疗程、适用条件与先后取舍。

### 3.1 非小细胞肺癌（NSCLC）

- 早期、可手术：手术（切除范围按医生判断）／围手术期治疗（辅助化疗、辅助或新辅助靶向治疗、围手术期免疫治疗类别）。
- 局部晚期、不可手术：同步放化疗，之后有巩固治疗这一类别。
- 晚期 / 转移 / 复发：化疗／按驱动基因结果划分的靶向治疗类别（检测目录含 EGFR、ALK、ROS1、BRAF、NTRK、RET、MET、KRAS、HER2、NRG1 等，据 IASLC 分子检测图谱目录）／免疫治疗（单药与联合两类）／抗血管生成类／寡转移灶的局部放疗或手术。
- 驱动基因未明或检测未完成时，本台只给术语与检查目的说明，**不匹配具体药物卡片**。

### 3.2 小细胞肺癌（SCLC）

- 局限期：放化疗（同步或序贯），少数情形下讨论手术；之后有巩固 / 维持这一类别。
- 广泛期：化疗联合免疫治疗类别；后线治疗的化疗与临床研究。

### 3.3 贯穿全程

- 支持治疗：症状与不良反应记录、营养、心理与照护者支持。
- 长期管理：复查节奏与戒烟等，只把「约在哪天、做了没有」整理成时间线。

## 7 本项目教训

- **NSCLC 与 SCLC 一开始想合成一段「肺癌的治疗大概有这些」**，写到一半发现两条路径的分期体系、检测前提、治疗类别都不共用，合并就等于误导。现在拆成两节，并在定义段写明「不合并叙述」。
- **TNM 与局限 / 广泛期差点被当成可换算的两套刻度**。`GUIDELINE-SCOPE.md` 第 3 条已经写了答案：SCLC 的局限 / 广泛期是「另一维度」，两套并列存放、不互推。README 照此写，不写「广泛期相当于 IV 期」。
- 趋势段只写 FDA 已发生的批准事件，且统一标「批准日待核」——`SOURCES.md` 本轮核对的是通知摘要，没核到批准日与批件号，不能凭印象补齐。
