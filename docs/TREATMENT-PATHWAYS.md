# NSCLC/SCLC治疗情境与患者理解合同 v0.2

以下按[NCI NSCLC患者版](https://www.cancer.gov/types/lung/patient/non-small-cell-lung-treatment-pdq)、[SCLC患者版](https://www.cancer.gov/types/lung/patient/small-cell-lung-treatment-pdq)构建教育与记录分类；不是选方案引擎。医学条目发布前仍需核对本地指南/标签及专业审阅。

| 情境 | 患者需理解的区别 | 产品记录与可讨论问题 |
| --- | --- | --- |
| NSCLC可手术/早期评估 | 影像期别、病理、能否切除和能否耐受手术不是一个结论；手术和适用情境的局部放疗可有不同任务 | 团队手术/放疗建议、肺功能等已有评估、术前取材/术后病理、手术方式/切缘/淋巴结原文；问“目标是什么、为什么此路径、还缺哪些条件” |
| NSCLC围手术期 | 新辅助、辅助与围手术治疗含义不同；手术结束不自动代表无需后续讨论 | 方案目的、术前/术后实际事件、病理与分子/PD-L1背景、团队安排，不按分期一键生成统一处方 |
| NSCLC局部晚期 | 可切除与不可切除需团队判断，放化疗及后续系统治疗存在不同条件 | MDT/放疗/化疗时间与是否进展、相关检测、后续讨论依据；靶向/免疫不能互相替换成同一“巩固药” |
| NSCLC转移性/复发 | 特定驱动改变、病理、PD-L1、前治与身体情况影响沟通方向；局部与全身治疗可并行 | 分子/PD-L1及缺项、已有候选路径的条件、个人偏好/担忧、实际治疗和部位变化；没有驱动改变不等于没有治疗 |
| NSCLC进展/耐药 | 单项指标变化、影像报告和团队疗效评估不同；时间/部位与再检测背景重要 | 当前/既往治疗、报告比较对象、再活检/血浆检测、局部/多部位描述、试验资料；不自动切换下一线 |
| SCLC局限期 | SCLC有独立路径；胸部放化疗、部分特定情境手术及后续治疗需要团队解释 | 局限/广泛期与TNM原文、放化疗时序、实际分次/药物、后续免疫/观察讨论及来源 |
| SCLC广泛期 | 以系统治疗等综合方式讨论，不能套用NSCLC的基因→TKI列表 | 初始/维持阶段、含铂/依托泊苷等实际方案原文、免疫与局部放疗记录、症状与团队目标；具体药物和组合按地区条目 |
| SCLC复发/后线 | 前次治疗、距上次治疗时间、耐受与目标重要；不同机制药物/研究有各自条件 | 保留确切日期、前治/不良反应、可讨论后续路径/研究；不自动计算一个间隔阈值就下处方 |
| 混合型/转化 | 与单一原发SCLC不可默认相同；历史病理和治疗仍有价值 | 前后标本/病理及医生判断、关联分子材料、MDT问题；不从症状或标志物推断转化 |

上述分类借鉴临床背景，但真正交互是“理解我的已有材料/团队方案、辨别未知、准备问题、回顾实际过程”。不能把表格渲染为患者必须逐项完成的治疗路线。

## SCLC必须追上的知识变化

不能再用“只有化疗”概括SCLC。例：[FDA 2024-12-04 durvalumab通知](https://www.fda.gov/drugs/resources-information-approved-drugs/fda-approves-durvalumab-limited-stage-small-cell-lung-cancer)涉及局限期同步含铂放化疗后未进展的条件；[FDA 2025-11-19 tarlatamab通知](https://www.fda.gov/drugs/resources-information-approved-drugs/fda-grants-traditional-approval-tarlatamab-dlle-extensive-stage-small-cell-lung-cancer)涉及既往含铂后进展的广泛期人群。它们是美国批准事件样例，不证明中国当前可及。

SCLC目录需能记录化疗、免疫、后线药物、DLL3相关T细胞衔接药物等类别，不能把tarlatamab当EGFR类口服TKI；是否需要DLL3检测不能由“药物靶点名”自动推断。PCI与脑MRI监测的讨论保留认知/生活顾虑及医生解释；PCI不等同治疗已确诊脑转移。

## 各治疗方式最少记录

手术：实际日期/术式/病理号/切缘淋巴结原文/恢复与建议；放疗：靶区、技术、计划及实际分次/剂量原文、同时系统治疗、暂停及症状；系统药物：方案/单药、用途、医嘱与实际、周期/线次未知允许、暂停变更来源。

免疫/靶向/放疗期间相同的咳嗽、气促或腹泻可能需不同评估，系统不从时间关联判断病因。保存症状发生、治疗背景与团队回复，帮助清楚表达；[NCI免疫副作用教育](https://www.cancer.gov/about-cancer/treatment/types/immunotherapy/side-effects)作为经审阅内容的准备来源，不让模型自动给停药/激素方案。
