# 患者场景与信息差 v0.2

通用原则：患者/照护者从任务进入；输入可少，出处可查；来源冲突保持未知。所有步骤是产品提案，不是自动医疗路径。E/H来源见USER-RESEARCH。

| ID/角色/触发 | 最少输入与过程 | 结果/回顾/失败恢复 |
| --- | --- | --- |
| S01 患者或家属刚获疑似/确诊消息 | 无资料也可开始；承接感受→自选想弄懂/准备沟通/先暂停→区分报告已写与尚未明确 | 可读懂的短说明、自选问题/下一步；没档案/没家属/无模型仍有维护过的通用入口；保存个人内容时才选目录 |
| S02 被建议穿刺或等待检测 | 一张预约/报告即可；看取材目的说明→记院方须知→关联标本/病理/分子/PD-L1→显示待出/不足/送检联系 | 标本关系图与未完成事项；重复取材先保留团队理由，患者可问替代方式/风险；不自动安排停药或认定安全 |
| S03 病理/分期与治疗方案初谈 | 选报告；显示病理与分期原文/日期/体系→记录团队提出路径和目标→列未明条件 | 诊断/阶段沟通页；NSCLC/SCLC/混合与未定均能开始，不从吸烟史、标志物或单影像确定类型 |
| S04 NSCLC获得分子/PD-L1结果或已有靶向药 | 选检测/药盒/处方或提问；解释具体改变→列知识卡的条件与地区→对照本人已知/未知→保存个人医嘱和疑问 | 检测-用药问题卡；没检出/样本不足可继续一般解释，不能默认无靶点；无可靠当前来源只整理问题，不编治疗 |
| S05 SCLC治疗中 | 选方案/预约；局限/广泛期与TNM分开→连接化疗、胸部放疗、免疫、脑监测/PCI原文→记录完成和团队回复 | 独立SCLC近况与问题；复发不套EGFR路径；病理转化保留前后依据，不能默认既往基因决定当前方案 |
| S06 转移/局部进展被提出 | 报告或患者自述→标证据层→按部位并列影像/治疗→解释局部与全身的任务区别→准备MDT/再检测问题 | 可回源的部位/治疗表与询问清单；未给比较对象不作进展；突发严重症状有直接联系入口，不等AI |
| S07 今天精力不足 | 可只记一句话/进食变化/症状→选是否保存及给谁看→获得支持信息/拟询问问题→可停止 | 不填完量表也能获得帮助；无网络保留本机草稿；不以记录次数奖励或责备，记录不等于临床处置 |
| S08 复诊与跨院 | 一批报告或已有档案→系统去重/排序/短草稿→可跳过疑点→选择日期/重点问题→预览分享/导出 | 短近况＋一图秀＋问题清单；默认接受记录，草稿明确选入并标状态；导出失败可重试不丢选择，取消不生成假文件 |
| S09 术后/随访 | 已有团队复查计划或自定事项→可回忆记录术前活动基线→术后以相同低负担问题记录活动/气促变化→回顾症状和安排 | 自述与临床肺功能检查分开；可只填一项；两次记录可比但不分级、不判断恢复是否正常；明显新发/加重可联系团队 |
| S10 试验/舒适照护与照护者支持 | 主动选择需求→来源检索/登记条件并列个人资料→选问题/收藏/联系前核验 | 来源快照和沟通包；无数据仅原始链接时明确能力降级。舒适照护可与抗肿瘤治疗并行，不暗示“已放弃” |

| S11 免疫治疗中出现新变化 | 选当前/既往免疫治疗记录→可选记录气促/咳嗽、腹泻、皮肤变化、发热、乏力或其他变化→查看本人团队联系信息 | 症状与暴露日期同窗；不推断irAE、不提供自行停药建议；提示清单须临床审核，未记录不代表无症状 |
| S12 胸水/气促再次处理 | 记录诊断性穿刺或治疗性引流→逐次保存日期、侧别/部位原文、量/单位、性状、来源及气促自述→关联影像/细胞学 | 同日多次不合并、缺项显式保留；可回到操作记录/报告；不推断复发/疗效或引流时机 |

## 患者信息差优先级（设计判断，待走查）

最先解释：我现在确定了什么/还缺什么；这份材料为何影响下一步沟通；我该向谁问什么。先呈现短说明和问题，字段/药理/指南章节按需展开。

其次贯通：穿刺不是分子检测本身；确诊、组织学、分期与靶点不同；检查已送/检出/能用药不同；治疗目标与线次、局部与全身不同；复诊比较需要可比报告和实际治疗时间。

日常持续帮助：药怎么按已有医嘱记录、需要告诉团队什么、哪些支持可问、费用去哪里核实、家属如何协助且尊重本人想知道多少。不是把患者训练成肿瘤科医生，也不能把药物知识全部交给外部链接。

## 需要比较的入口方案

A 按病理/阶段先填长表：知识定位快，但不适合刚确诊和低精力用户。
B 全部对话：开始自然，但多来源/时点与记录难以持续回顾。
C 任务入口＋可回源草稿＋结构化底层＋原生Agent：建议采用，兼顾早获得帮助与长期复用；代价是必须解释草稿/接受区别，需原型验证。

全病程是覆盖范围，并非强制患者逐阶段通关。日常理解与复诊共享问题ID/记录版本；患者可随时进入任何适用模块。
