# 转移、进展后再评估与支持照护 v0.2

转移治疗并非肺癌独有；本模块面向肺癌的高频组合和沟通任务。医学背景见[NCI转移癌说明](https://www.cancer.gov/types/metastatic-cancer)、[ACS肺癌放疗](https://www.cancer.org/cancer/types/lung-cancer/treating-non-small-cell/radiation-therapy.html)、[骨转移患者资料](https://www.cancer.org/cancer/supportive-care/advanced-cancer/bone-metastases.html)。知识与安全提示正式上线前需专业审核。

## 部位事件卡（不是自动诊断）

| 情境 | 应整理的材料与已发生事项 | 患者/家属可准备的问题 |
| --- | --- | --- |
| 脑/中枢神经系统 | MRI/其他报告、比较对象、症状自述、SRS/WBRT/手术实际记录、全身药物、团队意见 | 哪些病灶已确认、局部和全身治疗如何协调、有哪些认知/生活影响、复查怎么按团队计划做 |
| 脑膜相关描述 | 报告/专科文书、疑似或明确状态、已有检查/治疗和功能变化 | 是否需要专科进一步明确、现有材料能说明什么；不因头痛自动识别脑膜转移 |
| 骨/脊柱 | 报告部位、疼痛/行动能力、放疗/骨保护/牙科与已有专业建议、骨折或脊髓压迫文书 | 活动/疼痛与复查需要怎样沟通、骨保护相关准备与监测按谁的医嘱；不自动给运动或补钙处方 |
| 胸膜/胸水 | 影像、细胞学、引流/胸膜处理、实际引流记录及气促自述 | 病因/恶性证据是什么、送检与处理安排如何理解、什么变化需按团队说明联系 |
| 肝/肾上腺/其他 | 部位/证据状态/报告比较、相关检查和局部/系统治疗记录 | 是否已确认为转移、是否有其他解释、影响整体路径的哪些条件还不明 |
| 局部少数部位变化/多部位变化 | 各部位独立报告和时间、实际治疗暴露、团队评价 | 是否需要MDT讨论局部与全身策略、再取材/再检测的目的是什么，不自动断言寡进展 |

影像只读文字报告及医师结论，不读取DICOM进行诊断/RECIST自动测量。记录靶病灶尺寸原文可供回顾，但方法/比较对象不明确时不绘制肿瘤总负荷或推出进展百分比。

## 再评估闭环

选择变化来源→分开报告描述与团队判断→回顾实际治疗/依从性自述与症状→记录团队提出的进一步检查/再取材原因→新标本/检测与历史关联→形成问题/实际决定→回顾结果。缺新检测并不阻塞患者准备沟通，系统不自动要求重复所有检查。

耐药机制、组织学转化及寡进展均为需出处的断言。临床试验对照使用明确版本，不能将尚未核对的进展/分子结果当已符合条件。

## 及时联系帮助的具体产品行为

在可展开帮助区与相关症状入口提供短的经审核提示，例如突发严重气促/大量咯血、新发抽搐或明显神经异常、严重背痛伴无力或大小便变化，应能直接联系急救/医疗团队。此处为帮助卡的内容范围提案，**不是已验证完整分诊规则**；不定义未经审阅的阈值、等待时间或概率评分。对正在发生的明显紧急情况，不以先上传病历/填量表/等待AI答复作前置。

保存院方给出的紧急联系/术后观察与用药注意原文、地区和更新日；无联系人也有官方急救查找说明。软件不承诺监控生命体征或自动通知医院。用户选择记录联系结果后，进入症状/问题回顾，而非自动写“风险解除”。

## 支持照护与患者目标

抗肿瘤治疗之外，可主动选择疼痛/气促/睡眠、营养、心理、活动与照护者帮助。舒适/姑息照护可以与抗肿瘤治疗并行；不把转移自动标“终末期/放弃”。记录本人在意事项及分享选择，支持照护沟通一期保留；远程专业转介平台或独立丧亲空间为后续增强，当前不显示可承诺服务的按钮。
