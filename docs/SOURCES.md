1. 取得并审读卫健委指南全文及可用的CSCO 2026 NSCLC/SCLC完整版本；整理章节、页码、地区/证据级别、发布日期和允许引用方式。
2. 当前NMPA药品说明书、伴随诊断、医保支付目录/政策及省市可及性核验；每药单独记更新时间。
3. 更多中国SCLC、穿刺/分子检测体验、低资源地区、老年与照护者研究；补偿访谈/走查。
4. 医学审核者复核病理、分期、药品及紧急提示内容。未经审核的本文件只作产品设计材料。
