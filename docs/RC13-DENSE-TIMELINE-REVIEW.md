# RC13 密集病程遮挡曲线修复

2026-10-20，用户用108条记录的SCLC病例反馈：病程堆积使曲线不可见。根因是placeEventLanes按标签碰撞无限增加行，曲线plotTop随行数累加，事件又挤在12个月窗的后半段，整张SVG被撑成数千像素。

修复：趋势SVG固定viewBox `0 0 1000 292`，先展示曲线。事件移到下方固定六类轨道；同类别临近日期聚合，显示数量及原始日期范围，保留每条来源/状态，不把聚合当成新病历。点击聚合显示成员列表，点击原始记录看来源。原始病程按日期折叠，260px独立滚动；左侧指标目录280px独立滚动；治疗轨260px独立滚动。数据不删减，仍可逐项展开。

自动测试51/51通过：新增500事件聚合无丢失、分类不混合、保留日期映射，以及108条SCLC病例曲线固定高度/原始记录来源交互。浏览器1280×720：曲线top245px/bottom467px、1条NSE曲线、35条病程记录聚合22节点；点击4条节点可查看2026-05-25/05-29/06-01/06-05四条原始记录；1600×1000曲线bottom553px，仍在首屏。截图位于 `output/playwright/rc13-dense-1280.png`、`rc13-dense-1600.png`。浏览器为隔离合成资料环境，非实际宿主人工验收。安装证据见 `reviews/rc13-desktop-install.json`。
