## taste选择与媒介翻译

情绪目标：安心，同时容易看懂。主基因：瑞士平面的网格、对齐和清晰信息层级；辅基因：透明光影的浅蓝、柔和留白。只借用辅助风格的色调与空间感，正文和数据保持足够对比，不照搬低对比文字。

实际读取taste的 references/moods/09-清晰理性.md、references/moods/02-梦幻治愈.md、references/code-genes/01-瑞士平面.md。为适合患者端，主基因微圆角调整为统一16px内容容器；不复制硬朗的商业仪表盘，不将Logo的3D质感扩散成所有按钮的拟物阴影。

## 色彩合同

下列为依Logo目视建立的设计衍生色，不宣称是精确像素取样。浅蓝来自背景/机器人，暖橙来自肺部与心形；白与深蓝承担阅读。常规页面控制为蓝、橙、白、深蓝四个色族，状态色按实际语义另行设计。

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 品牌浅蓝 | #83C4DF | 品牌装饰与插画呼应，不用于白底小字 |
| 页面/浅色分区 | #F3F9FC / #E5F3F9 | 安静背景、选区与分组 |
| 主操作深蓝 | #17638C | 白字主按钮、链接、焦点 |
| 正文/次级文字 | #203D50 / #496777 | 阅读和说明 |
| 暖橙/浅橙 | #E8873D / #FFF1E5 | 少量品牌点缀，不表示恶化或医学风险 |
| 橙色文字 | #9B4613 | 浅橙底上可读的强调文字 |
| 表面/边线 | #FFFFFF / #CDDFE9 | 内容表面、非关键分隔线 |

浅蓝底和橙色不能直接配小号白字；文字与背景至少4.5:1，大字/关键非文本组件至少3:1，待具体组件验证。图表用蓝色序列、明确刻度与文字标签；不靠颜色区分计划/实际、候选/已接受或疾病状态。暗色模式采用同色族深蓝底，Logo仍保留其原图背景，不强制反色。

## 可执行UI/UX规则

- 任务区按容器宽度布局，清晰分组和左对齐；8px间距基线，组内16px、组间24–32px。
- 中文正文16px/1.65，大字19px；次级说明建议不小于14px，正文不压成密集指标墙。
- 主操作触达区至少44px，明显键盘焦点；状态有文字，加载/失败/重试可辨。
- Logo承担欢迎与陪伴感；语气尊重成人患者，不用卡通积分或强制积极文案。
- 后续按已确认主线覆盖全病程，治疗与复诊优先。草稿优先和可跳过核对仍是待确认的交互建议，不因视觉定稿自动视为已接受。
- 保留宿主导航、设置与原生Agent，样式限定业务区域；长弹窗固定标题与关闭入口，内容独立滚动。
- 尊重减少动效设置，不让Logo持续浮动或旋转；页面信息靠结构和留白表达，不铺满蓝色渐变与卡片阴影。

## HVT 肺癌专用页面与状态补充

- **取材链页面**：送检中、待出、样本不足、失败/需补材料分别显示状态文字、最近更新时间、对应标本/项目和患者可执行的行政下一步（查看院方须知/联系送检机构/稍后补记录）；不能自动建议重复穿刺。
- **分子到用药三段布局**：①检测结果与样本原文；②按病理/改变/阶段/地区标注条件的知识卡；③患者个人处方/服用自述/待问问题。三部分有清晰分隔和引用，不能把知识内容伪装成处方。
- **治疗事件图例常显**：手术、系统治疗、放疗和检查各用形状/图标加文字；计划、已实际完成、暂停分别有形状和状态文字。只用颜色不合格。
- **术后功能自述**：在术后/随访任务里显示“患者自述 · 不是肺功能检查”；术前回忆和术后自述的时点明确，支持跳过和单项保存，趋势只称“自述变化”。
- **胸水操作**：同日重复操作呈多个独立事件，摘要可折叠但不合并记录；缺字段写“未记录”。操作类型、侧别/部位、量、性状与出处可展开。
- **免疫治疗症状**：从个人治疗事件进入，提供可选自述项目和“其他”；不出现“irAE风险”或由模型推断。正式用语和求助等级待临床审核。
- **脑部病灶词汇**：页面与搜索索引并列“脑转移/脑部病灶”和“中枢神经系统”；报告原文、临床确认状态分层，不因患者搜索词就标为已确诊。
- **咯血入口**：从任意页面可达，支持不填完表单直达帮助；“痰中带血/咯血”作为普通语言词条可搜到。只显示本地审核后的联系动作；不显示“少量可等下次复诊”。急救入口离线可用。
