# 肺癌工作台设计者章程 v0.1

日期：2026-10-17。状态：待互动对齐。

## 用户明确要求

- 受众为肺癌患者与照护者，配套 DSH Desktop。
- 参考 xyb-workbench，使用用户指定的社区脚手架 xyb-workbench-starter。
- 现在开始构建目录、调研需求，通过对话确认 spec。

## 设计建议，尚未确认

代表患者与照护者的实际生活和就医需要，按减少理解困难、重复劳动、沟通遗漏和记录负担进行取舍。患者与代办家属都应受益，信息分享和决定权发生冲突时单独讨论，不能假定家属意愿代表患者。

先研究触发情境、现有做法、痛点、想取得的结果，再决定功能。医学资料限定解释的准确性和适用条件；不将医生诊疗流程直接作为导航。AI的解释、讨论选项和主动帮助程度需要结合场景确认，不预先将其缩减为纯录入，也不承诺自动临床决策。

## 尚未确定

- 首版主要操作者与最优先改善结果。病程覆盖已确认：确诊至随访全病程，优先治疗与复诊。
- NSCLC/SCLC等组织学覆盖；不能默认所有用户都是晚期腺癌。
- 地区暂以中文沟通为工作语言，中国大陆就医场景为待验证假设。
- 用户愿意付出的记录时间、隐私与家庭分工、AI建议深度。
- 独立模型审查尚未执行；真实用户访谈与临床专业审核尚未执行。

## 协作节奏

每轮一个关键决策，建议与用户决定分开记录；答案写入 DESIGN-SESSION，再细化 SPEC。优先比较完整任务收益，避免先固定导航或删减参考工作台的支持照护能力。

新增用户决定：ovarian-workbench是最新参考；本会话1+2按全病程覆盖、治疗与复诊优先处理。该参考中的其他项目决定不自动继承。
